# oligogym-bench

Container image + calibration harness for reproducing the benchmark of
*OligoGym: Curated Datasets and Benchmarks for Oligonucleotide Drug Discovery* (Roche).

Derived from [Roche/oligogym](https://github.com/Roche/oligogym) @ `97f5b9f` (Apache-2.0).
Upstream copyright and license are retained; see `NOTICE`.

One image serves both AWS Batch compute classes (CPU c6id/r6id/m6id and GPU g4dn/T4).
